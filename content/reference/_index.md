# Reference

One page: **[Catalog and API](/reference/api/)**, generated by
`scripts/gen_reference.py` from `static/captures/manifest.json`.

## Why this is generated and not written

The manifest is produced by `cmd/capture` in the framework repository, by
constructing each widget and rendering it. So a row on that page is a fact about
a widget that was built, not a claim someone typed. When the framework adds a
widget, the reference page picks it up on the next run — and when a constructor
changes, the page changes with it or the build check fails.

**The authority on signatures is still [pkg.go.dev](https://pkg.go.dev/github.com/serkanalgur/termmosaic).**
It is generated from the source and cannot be out of date. This page exists for
the things godoc does not carry: `MinSize()`, the capture widths and heights, and
which package each widget belongs to.
