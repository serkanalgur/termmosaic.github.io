Dialog

dialog.New(r buffer.Rect, v dialog.Variant) *dialog.Dialog — widgets/dialog

A modal box with a title, a body and a row of actions.

Modal: keys do not reach the tree beneath. The focused action is ringed rather than coloured - a bracket pair of the same width as the idle pair, so moving focus never reflows the row - and reinforced with reverse video, which survives NO_COLOR because colour is suppressed only at encode time. Escape is Cancel, never a no-op.

MinSize() = 28 × 4 cells
