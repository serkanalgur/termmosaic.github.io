Checkbox

form.NewCheckbox(r buffer.Rect, label string) *form.Checkbox — widgets/form

A tri-state box: unchecked, checked, or indeterminate.

Indeterminate is never produced by toggling. Only an application that has computed it from its children can set it, so the capture sets it directly.
