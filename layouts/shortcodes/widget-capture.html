{{- /* widget-capture — embed one widget's captured frames. Usage: {{< widget-capture "gauge" >}} Everything this renders comes from two generated files in static/captures/, which are build artefacts of the framework repo (cmd/capture) and are never edited here: manifest.json widths, heights, MinSize, summary, note .html the cell-grid frames at each width, plus the plain-text form .txt the exact plain-text cell grid The shortcode deliberately does NOT re-derive any of that. It slices the widget's own HTML fragment out of the generated page and hands it through, so the picture on this site is the picture the framework's own tests assert on. What it will not claim, and says so on the page: - a capture is one settled frame. It cannot show a keypress, a resize, a selection moving or anything animated. - it is the cell grid the renderer produced, not a screenshot of anyone's terminal: not their font, their colour scheme, their background, or their terminal's wide-glyph behaviour. - Braille and Block Elements can take a different advance width in a web font than in a terminal, which destroys the alignment those five widgets depend on. The plain-text capture is the honest form and it is always shown. */ -}} {{- $slug := .Get 0 -}} {{- if not $slug -}} {{- errorf "widget-capture: missing slug argument" -}} {{- end -}} {{- $captureDir := "static/captures" -}} {{- $manifest := readFile (printf "%s/manifest.json" $captureDir) | transform.Unmarshal -}} {{- $entry := "" -}} {{- range $manifest.widgets -}} {{- if eq .slug $slug -}}{{- $entry = . -}}{{- end -}} {{- end -}} {{- if not $entry -}} {{- errorf "widget-capture: %q is not in static/captures/manifest.json" $slug -}} {{- end -}} {{- $htmlPath := printf "%s/%s" $captureDir $entry.html -}} {{- $raw := readFile $htmlPath -}} {{- /* Slice out the fragment: everything from
to . The generated page's own , title block and note are deliberately left behind — the page here already says what the widget is, and duplicating the generated

would give every widget page two h1 elements. */ -}} {{- $parts := split $raw `
` -}} {{- if lt (len $parts) 2 -}} {{- errorf "widget-capture: %s has no tm-widths block; the generator's markup changed" $htmlPath -}} {{- end -}} {{- $fragment := printf `
%s` (index $parts (sub (len $parts) 1)) -}} {{- $fragment = index (split $fragment "") 0 -}} {{- $fragment = trim $fragment " \n\r\t" -}}
